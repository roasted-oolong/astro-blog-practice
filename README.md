# Astro Blog

A modern, fast-loading blog built following the official Astro tutorial to learn static site generation and component-based architecture. Demonstrates working with modern JavaScript frameworks and optimized performance practices.

## About

This blog project was built by following Astro's official tutorial and uses static site generation to create a lightning-fast, SEO-friendly website. The project emphasizes performance optimization, component reusability with Preact, and modern web development practices. Content is written in Markdown and transformed into static HTML at build time.

## Built With

- Astro
- Preact (for interactive components)
- JavaScript
- Markdown
- HTML/CSS
- Bun (package manager)

## Key Features

- Static site generation for optimal performance
- Component-based architecture
- Markdown-based content management
- Responsive design for all devices
- Fast page loads with minimal JavaScript
- SEO-optimized with meta tags and semantic HTML

## Getting Started

### Prerequisites

- Node.js 18+
- Bun (package manager)

### Installation

1. Clone the repository
```bash
git clone https://github.com/roasted-oolong/astro-blog.git
cd astro-blog
```

2. Install dependencies
```bash
bun install
```

3. Start the development server
```bash
bun run dev
```

4. Visit `http://localhost:4321` in your browser

### Build for Production

```bash
bun run build
```

## What I Learned

Following the official Astro tutorial introduced me to static site generation and the concept of "islands architecture", how modern frameworks optimize performance by shipping minimal JavaScript to the browser. I learned how to integrate Preact components for interactive elements while keeping the site mostly static, and got hands-on experience with Bun as a faster alternative to npm/yarn.

The tutorial approach helped me understand the full workflow of building with Astro: from project setup, to creating reusable components, to deploying a production-ready site. Working through structured documentation taught me how to read and implement framework-specific patterns effectively.
